## 使用方法

用户可以通过以下方式使用文档管理功能：
1. 点击顶部"知识库"标签页进入文档管理界面
2. 使用搜索框快速查找文档
3. 点击"新建文档"按钮创建新文档
4. 在文档列表中直接编辑或删除文档
5. 支持富文本内容和自定义元数据

## 技术特点

- 基于Element Plus组件库构建
- 采用Composition API + TypeScript
- 支持实时搜索和筛选
- 提供友好的用户交互体验
- 具备完整的CRUD操作能力
