# Malou Agent Desktop 快速加载指南

## 🚀 快速启动说明

本指南提供项目快速加载和开发的标准化流程，确保agent能够准确理解项目状态并高效工作。

## 📋 核心配置文件

### 1. 项目知识库索引
- **文件**: `PROJECT_KNOWLEDGE_BASE.md`
- **用途**: 项目整体概览和技术架构索引
- **加载时机**: 每次会话开始时自动加载
- **关键信息**: 技术栈、模块状态、目录结构

### 2. 记忆系统配置
- **文件**: `.codebuddy/memory-config.json`
- **用途**: 定义记忆结构和加载策略
- **加载时机**: agent初始化时自动加载
- **关键配置**: 记忆类型、保留策略、自动加载列表

### 3. 项目快照
- **文件**: `.codebuddy/contexts/project-snapshot-*.md`
- **用途**: 当前项目状态和开发重点
- **加载时机**: 需要了解当前状态时加载
- **关键信息**: 任务状态、技术挑战、开发建议

## 🔄 标准加载流程

### 步骤1: 基础信息加载
```yaml
加载文件:
  - PROJECT_KNOWLEDGE_BASE.md
  - .codebuddy/memory-config.json
  - README.md

关键信息:
  - 项目名称和技术栈
  - 当前开发状态
  - 主要功能模块
```

### 步骤2: 开发上下文加载
```yaml
加载文件:
  - .codebuddy/contexts/project-snapshot-最新日期.md
  - .codebuddy/plans/当前活跃计划.md
  - PROJECT_SUMMARY.md

关键信息:
  - 当前开发任务和优先级
  - 技术挑战和解决方案
  - 近期开发目标
```

### 步骤3: 技术细节加载
```yaml
加载文件:
  - 相关源代码文件
  - 技术文档
  - 配置文件和依赖

关键信息:
  - 具体实现细节
  - 代码结构和API
  - 依赖关系和配置
```

## 📊 记忆系统使用指南

### 记忆类型说明

| 记忆类型 | 存储位置 | 保留策略 | 使用场景 |
|----------|----------|----------|----------|
| **计划记忆** | `.codebuddy/plans/` | 长期保留 | 项目规划和路线图 |
| **规则记忆** | `.codebuddy/rules/` | 长期保留 | 开发规范和最佳实践 |
| **上下文记忆** | `.codebuddy/contexts/` | 会话期间 | 当前开发状态和任务 |
| **快照记忆** | `.codebuddy/snapshots/` | 30天保留 | 项目状态历史记录 |

### 记忆更新策略

#### 自动更新
- **项目快照**: 每次重大变更后自动更新
- **知识库索引**: 项目结构变化时更新
- **计划状态**: 任务完成时自动标记

#### 手动更新
- **技术文档**: 功能开发完成后更新
- **配置说明**: 配置变更时更新
- **问题记录**: 发现问题时记录

## 🚨 常见问题解决

### 问题1: 记忆加载失败
**症状**: agent无法正确识别项目状态
**解决方案**:
1. 检查`.codebuddy/memory-config.json`文件完整性
2. 验证项目知识库索引文件是否存在
3. 重新生成项目快照

### 问题2: 信息不一致
**症状**: 不同文件中的信息相互矛盾
**解决方案**:
1. 检查文件更新时间戳
2. 更新过时的文档
3. 统一信息源，删除重复内容

### 问题3: 加载性能问题
**症状**: 加载过程缓慢或卡顿
**解决方案**:
1. 优化文件大小，拆分大文件
2. 使用缓存机制
3. 配置合理的预加载策略
