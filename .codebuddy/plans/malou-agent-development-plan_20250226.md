# Malou Agent Desktop 开发路线图

## 🎯 项目愿景

打造一个现代化的桌面AI代理应用，具备本地AI推理能力、智能文档管理和流畅的用户体验。

## 📊 当前状态评估

### 已完成功能 ✅
- **基础架构**: Tauri + Vue 3 + Rust 项目结构搭建完成
- **前端界面**: 聊天界面、文档管理、配置界面基础实现
- **后端服务**: 数据库访问层、配置管理系统、聊天服务模块
- **通信机制**: 前后端API通信机制建立

### 技术挑战 ⚠️
- **Rust编译问题**: time crate版本冲突导致编译失败
- **AI推理集成**: ONNX推理引擎依赖问题待解决
- **向量搜索**: ChromaDB集成尚未实现

## 🚀 开发阶段规划

### 阶段一：技术问题解决 (1-2周)
**目标**: 解决当前技术障碍，确保项目可编译运行

#### 任务清单
- **P1**: 解决time crate版本冲突问题
  - 分析依赖树，识别冲突根源
  - 调整Cargo.toml依赖版本
  - 验证编译通过
  
- **P1**: 修复Rust编译错误
  - 检查所有编译错误
  - 更新不兼容的API调用
  - 确保后端可正常启动
  
- **P2**: 优化agent记忆系统
  - 创建项目知识库索引
  - 标准化.codebuddy目录结构
  - 建立快速加载机制

### 阶段二：核心功能完善 (2-4周)
**目标**: 完善基础功能，提升用户体验

#### 任务清单
- **P1**: 激活ONNX推理功能
  - 解决tract库依赖问题
  - 集成本地模型推理
  - 实现AI对话功能
  
- **P1**: 实现文档管理完整功能
  - 完善文档CRUD操作
  - 实现文档搜索功能
  - 优化文档展示界面
  
- **P2**: 优化UI/UX体验
  - 实现Mac风格设计
  - 优化响应式布局
  - 提升交互流畅度

### 阶段三：高级功能开发 (4-8周)
**目标**: 实现高级AI功能，提升应用价值

#### 任务清单
- **P2**: 集成ChromaDB向量数据库
  - 实现向量嵌入存储
  - 构建语义搜索功能
  - 优化搜索性能
  
- **P2**: 实现技能插件系统
  - 设计插件架构
  - 实现插件加载机制
  - 提供插件开发接口
  
- **P3**: 添加多模态支持
  - 支持图像处理
  - 实现语音交互
  - 扩展输入输出方式
