# malou-agent AI记忆系统

## 概述

本目录包含 `malou-agent` 项目的专用AI记忆系统，用于支持各种AI开发工具的项目记忆管理。

## 目录结构

```
.ai-memory/
├── README.md              # 本文件
├── config.json           # 记忆系统配置
├── shared/               # 共享知识库
│   ├── best-practices/  # 开发最佳实践
│   └── templates/       # 项目模板
└── monitoring/           # 系统监控（预留）
```

## 配置说明

### config.json
- 项目专用记忆系统配置
- 包含性能优化、缓存策略、同步设置
- 支持任意AI工具的无缝集成

### 共享知识库
- **best-practices/**: 开发最佳实践和代码规范
- **templates/**: 项目模板和脚手架配置

## 使用指南

### 对于AI工具
- 所有AI工具均可读取本目录下的配置和知识库
- 记忆系统自动管理项目状态和开发进度
- 基于时间戳的智能冲突解决

### 对于开发者
- 无需手动配置，系统自动工作
- 项目状态实时同步和记忆
- 最佳实践和模板自动应用

## 技术特性

- **项目专用**: 专注于malou-agent项目的记忆管理
- **工具无关**: 支持任何AI开发工具
- **自动同步**: 智能记忆同步和冲突解决
- **性能优化**: 缓存策略和加载优先级管理

## 维护说明

本系统为自动维护，无需手动干预。系统会自动：
- 跟踪项目开发状态
- 管理技术栈和依赖关系
- 应用最佳实践和代码规范
- 监控系统性能指标
